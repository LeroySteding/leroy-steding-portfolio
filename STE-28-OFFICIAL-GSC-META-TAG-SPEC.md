## 📋 OFFICIAL META TAG FORMAT

### Exact HTML Tag (From Google Search Console)
```html
<meta name="google-site-verification" content="unique-verification-code-here" />
```

### Components
- **Tag Name**: `<meta>`
- **Name Attribute**: `google-site-verification` (always this exact name)
- **Content Attribute**: Your unique verification code (generated by Google)
- **Placement**: In the `<head>` section of your HTML

### Example with Sample Code
```html
<head>
  <title>Your Page Title</title>
  <meta name="google-site-verification" content="abcdef1234567890xyz" />
</head>
```
